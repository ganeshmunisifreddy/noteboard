# Kanban Boards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Named kanban boards with columns, where every card is a normal note, reachable from a Boards chip, with drag/keyboard moves, a Done column linked to dates, backup v4 and an editor Board picker.

**Architecture:** Two new Dexie tables (`boards`, `columns`, schema v5) and three new note fields (`boardId`, `columnId`, `boardPosition`), so every record syncs on its own. Board rules live in `lib/boards.ts` (boards/columns) and `lib/cards.ts` (placing notes), sharing column-order helpers in `lib/places.ts`. The UI is a Boards view on the home page (`/?view=boards`), a board page (`/board?id=…`) under `components/kanban/`, and a Board picker in the note editor.

**Tech Stack:** Next.js 16 Pages Router, React 19 (React Compiler lint), Dexie 4 + dexie-react-hooks, Radix (`radix-ui`), dnd-kit core (already installed; no `@dnd-kit/sortable`), lucide-react, CSS Modules, Vitest + jsdom + fake-indexeddb + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-15-kanban-design.md`

## Global Constraints

- No server; data in IndexedDB via Dexie. No new dependency (dnd-kit core only, as the main board).
- Every record (board, column, note) stands alone with an id and `updatedAt`; no record holds a list another record also holds.
- `NoteChanges` must not include `boardId`, `columnId`, `boardPosition`: only board functions change them, so an editor draft save never moves a card.
- Board names: trimmed, required, max 60 characters, not unique. Column names: trimmed, required, max 40. Empty name error text: "Enter a name."
- Templates: Basic (To do · Doing · **Done**), Pipeline (Ideas · Next · In progress · Review · **Done**), Now / Next / Later (Now · Next · Later), Empty. Bold = Done column. At most one Done column per board.
- Moving within a column is not an edit (`updatedAt` unchanged); moving to another column, rename, column move, Done flag, remove from board are edits.
- Backup format version 4; versions 1–3 restore with every note on the main board; version 5+: "This backup is from a newer version of Noteboard."
- WCAG 2.2 AA; every drag action has a non-drag alternative (WCAG 2.5.7); functional text ≥ 11px (`--text-xs` = 12px).
- React Compiler lint must stay clean (`npm run lint`); no `Date.now()` during render, no ref writes during render.
- App copy is English. Don't run Prettier. Match file quote style (`'` in TS/TSX).

## Review Focus

1. **Deleting a column or board that holds archived or trashed cards**: those notes must move with the others, never keep a dangling `columnId` (restoring them later must land somewhere sensible). Pinned by `moves archived and trashed notes too` (Task 1).
2. **A repeating card dropped into the Done column of a board whose first column is the Done column**: it must stay in the Done column with its next date, not loop. Pinned by `keeps a repeat in place when the Done column is first` (Task 2).
3. **A backup note pointing at a column of a different board** (or a deleted one): it must land on the main board, not on a board it doesn't belong to. Pinned by `puts notes with a broken place on the main board` (Task 4).
4. **Typing a search while in the Boards view**: the search must switch to All with that query, not filter nothing. Pinned by `searches all notes from the Boards view` (Task 5).
5. **Menu moves in quick succession while the live query still shows the old order**: the second move must start from the order on screen, so a card doesn't jump back. Pinned by `moves twice in a row from the menu` (Task 7).

```ts
import { db } from './db';
import type { Column, Note } from './types';

const byId = (a: { id: string }, b: { id: string }) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0);

// Ties (e.g. from a restored backup) are broken by id, so the order never jumps.
export const byPosition = <T extends { id: string; position: number }>(a: T, b: T) =>
  a.position - b.position || byId(a, b);

export const byBoardPosition = (a: Note, b: Note) => a.boardPosition - b.boardPosition || byId(a, b);

export const sortedColumns = async (boardId: string) =>
  (await db.columns.where('boardId').equals(boardId).toArray()).sort(byPosition);

// Every note in a column, archived and trashed ones included (they keep their places).
export const columnNotes = async (column: Column) =>
  (await db.notes.where('boardId').equals(column.boardId).toArray())
    .filter((note) => note.columnId === column.id)
    .sort(byBoardPosition);

export const topOf = async (column: Column) => {
  const [first] = await columnNotes(column);
  return first ? first.boardPosition - 1 : 0;
};

export const endOf = async (column: Column) => {
  const notes = await columnNotes(column);
  return notes.length > 0 ? notes[notes.length - 1].boardPosition + 1 : 0;
};
```

```ts
const col = (name: string, done = false) => ({ name, done });

export const BOARD_TEMPLATES: { id: BoardTemplate; label: string; columns: { name: string; done: boolean }[] }[] = [
  { id: 'basic', label: 'Basic', columns: [col('To do'), col('Doing'), col('Done', true)] },
  {
    id: 'pipeline',
    label: 'Pipeline',
    columns: [col('Ideas'), col('Next'), col('In progress'), col('Review'), col('Done', true)],
  },
  { id: 'now-next-later', label: 'Now / Next / Later', columns: [col('Now'), col('Next'), col('Later')] },
  { id: 'empty', label: 'Empty', columns: [] },
];

export const BOARD_NAME_MAX = 60;
export const COLUMN_NAME_MAX = 40;
const NAME_REQUIRED = 'Enter a name.';

// Trimmed and cut to length; null when nothing is left.
export const cleanName = (name: string, max: number): string | null => name.trim().slice(0, max).trim() || null;

const required = (name: string, max: number) => {
  const clean = cleanName(name, max);
  if (!clean) throw new Error(NAME_REQUIRED);
  return clean;
};

export const createBoard = async (name: string, template: BoardTemplate): Promise<Board> => {
  const clean = required(name, BOARD_NAME_MAX);
  const columns = BOARD_TEMPLATES.find((t) => t.id === template)?.columns ?? [];
  const now = Date.now();
  return db.transaction('rw', db.boards, db.columns, async () => {
    const last = await db.boards.orderBy('position').last();
    const board: Board = { id: uuid(), name: clean, position: last ? last.position + 1 : 0, createdAt: now, updatedAt: now };
    await db.boards.add(board);
    await db.columns.bulkAdd(
      columns.map((c, index) => ({ id: uuid(), boardId: board.id, name: c.name, position: index, done: c.done, updatedAt: now })),
    );
    return board;
  });
};

export const renameBoard = async (id: string, name: string) => {
  const clean = required(name, BOARD_NAME_MAX);
  await db.boards.update(id, { name: clean, updatedAt: Date.now() });
};

// Notes leaving a board go to the top of the main board, keeping the board's order.
const toMainBoard = async (notes: Note[], now: number) => {
  let top = await nextTopPosition();
  const placed: Note[] = [];
  for (const note of [...notes].reverse()) {
    placed.unshift({ ...note, boardId: null, columnId: null, boardPosition: 0, position: top, updatedAt: now });
    top -= 1;
  }
  return placed;
};

export type BoardSnapshot = { board: Board; columns: Column[]; notes: Note[] };

// The board, its columns and its cards' places go together; the notes either
// return to the main board or go to Trash (archived and trashed ones too).
export const deleteBoard = async (id: string, notesTo: 'keep' | 'trash'): Promise<BoardSnapshot | undefined> => {
  const snapshot = await db.transaction('rw', db.boards, db.columns, db.notes, async () => {
    const board = await db.boards.get(id);
    if (!board) return undefined;
    const columns = await sortedColumns(id);
    const order = new Map(columns.map((c, index) => [c.id, index]));
    const notes = (await db.notes.where('boardId').equals(id).toArray()).sort(
      (a, b) => (order.get(a.columnId ?? '') ?? 0) - (order.get(b.columnId ?? '') ?? 0) || byBoardPosition(a, b),
    );
    const now = Date.now();
    const moved = (await toMainBoard(notes, now)).map((note) =>
      notesTo === 'trash' && note.trashedAt === null ? { ...note, trashedAt: now } : note,
    );
    await db.notes.bulkPut(moved);
    await db.columns.bulkDelete(columns.map((c) => c.id));
    await db.boards.delete(id);
    return { board, columns, notes };
  });
  if (snapshot) await refreshHasNotesMarker();
  return snapshot;
};

// Swaps a column with its neighbour; positions are renumbered 0, 1, 2, …
export const moveColumn = async (id: string, direction: -1 | 1) => {
  await db.transaction('rw', db.columns, async () => {
    const column = await db.columns.get(id);
    if (!column) return;
    const columns = await sortedColumns(column.boardId);
    const index = columns.findIndex((c) => c.id === id);
    const target = index + direction;
    if (target < 0 || target >= columns.length) return;
    const reordered = [...columns];
    [reordered[index], reordered[target]] = [reordered[target], reordered[index]];
    const now = Date.now();
    await db.columns.bulkPut(
      reordered.map((c, position) => (c.position === position ? c : { ...c, position, updatedAt: now })),
    );
  });
};

// At most one Done column per board.
export const setDoneColumn = async (id: string, done: boolean) => {

    if (!column) return;
    const now = Date.now();
    const changed = (await sortedColumns(column.boardId)).flatMap((c) => {
      const next = c.id === id ? done : done ? false : c.done;
      return next === c.done ? [] : [{ ...c, done: next, updatedAt: now }];
    });
    await db.columns.bulkPut(changed);
  });
};

  });

export type BoardSummary = { board: Board; columns: { id: string; name: string; count: number }[]; total: number };

export const summarizeBoards = (boards: Board[], columns: Column[], notes: Note[]): BoardSummary[] => {
  const counts = new Map<string, number>();
  for (const note of notes) {
    if (note.columnId && isActive(note)) counts.set(note.columnId, (counts.get(note.columnId) ?? 0) + 1);
  }
  return [...boards].sort(byPosition).map((board) => {
    const own = columns
      .filter((c) => c.boardId === board.id)
      .sort(byPosition)
      .map((c) => ({ id: c.id, name: c.name, count: counts.get(c.id) ?? 0 }));
    return { board, columns: own, total: own.reduce((sum, c) => sum + c.count, 0) };
  });
};

    if (note.columnId && isActive(note)) cards.get(note.columnId)?.push(note);
  }

  return cards;
};
```

```ts
import { db } from './db';
import { markDoneChanges, seenIfPast } from './due';
import { nextTopPosition } from './notes';
import { needsRenumber, positionBetween } from './order';
import { columnNotes, endOf, sortedColumns, topOf } from './places';
import type { Column, Note } from './types';

const renumber = async (column: Column) => {
  const notes = await columnNotes(column);
  await Promise.all(notes.map((note, index) => db.notes.update(note.id, { boardPosition: index })));
};

export type PlaceResult = { before: Note; dateChanged: boolean };

// Puts a note in a column between two of its cards (null = start or end).
// Moving to another column is an edit. Entering a Done column marks an open
// date done (a repeat that moves on goes back to the top of the first
// column); leaving one reopens a done date.
export const placeNote = async (
  noteId: string,
  columnId: string,
  beforeId: string | null,
  afterId: string | null,
  now = Date.now(),
): Promise<PlaceResult | undefined> =>
  db.transaction('rw', db.notes, db.columns, async () => {
    const [note, column] = await Promise.all([db.notes.get(noteId), db.columns.get(columnId)]);
    if (!note || !column) return undefined;
    const find = async (id: string | null) => (id ? ((await db.notes.get(id))?.boardPosition ?? null) : null);
    let before = await find(beforeId);
    let after = await find(afterId);
    if (needsRenumber(before, after)) {
      await renumber(column);
      before = await find(beforeId);
      after = await find(afterId);
    }
    const patch: Partial<Note> = { boardId: column.boardId, columnId, boardPosition: positionBetween(before, after) };
    let dateChanged = false;
    if (note.columnId !== columnId) {
      patch.updatedAt = now;
      const from = note.columnId ? await db.columns.get(note.columnId) : undefined;
      if (column.done && note.due && note.due.doneAt === null) {
        const done = markDoneChanges({ ...note, due: note.due }, now);
        patch.due = done.due;
        patch.items = done.items;
        dateChanged = true;
        if (done.due.doneAt === null) {
          const [first] = await sortedColumns(column.boardId);
          if (first && first.id !== columnId) {
            patch.columnId = first.id;
            patch.boardPosition = await topOf(first);
          }
        }
      } else if (!column.done && from?.done && note.due && note.due.doneAt !== null) {
        patch.due = seenIfPast({ ...note.due, doneAt: null, alertedAt: null }, now);
        dateChanged = true;
      }
    }
    await db.notes.update(noteId, patch);
    return { before: note, dateChanged };
  });

// At the end of a column: "Move to column" and the editor's Board menu.
export const placeAtEnd = async (noteId: string, columnId: string, now = Date.now()) => {
  const column = await db.columns.get(columnId);

export const moveInColumns = (

  activeId: string,
  over: DropTarget,

  const from = Object.keys(order).find((key) => order[key].includes(activeId));
  const to = over.type === 'column' ? over.id : Object.keys(order).find((key) => order[key].includes(over.id));

  if (over.type === 'column' && from === to) return order;

  const target = [...next[to]];
  const index = over.type === 'card' ? order[to].indexOf(over.id) : target.length;
  target.splice(index, 0, activeId);
  return { ...next, [to]: target };
```

```tsx
import { Dialog } from 'radix-ui';
import { useId, useState, type FormEvent } from 'react';
import { BOARD_NAME_MAX, BOARD_TEMPLATES, createBoard, type BoardTemplate } from '../../lib/boards';

const NewBoardForm = ({ onCreated, onCancel }: { onCreated: (board: Board) => void; onCancel: () => void }) => {

            setError(null);
          }}
        />

          {error}
        </p>
```

```tsx
import { useState } from 'react';
import styles from './Board.module.css';

type Props = {
  label: string; // e.g. "Column name"
  initial: string;
  maxLength: number;
  onSave: (name: string) => void;
  onCancel: () => void;
};

// Enter or leaving the field saves; Esc cancels. An empty name cancels.
const InlineName = ({ label, initial, maxLength, onSave, onCancel }: Props) => {
  const [value, setValue] = useState(initial);
  const finish = () => (value.trim() ? onSave(value) : onCancel());
  return (
    <input
      className={styles.nameInput}
      aria-label={label}
      value={value}
      maxLength={maxLength}
      autoFocus
      onChange={(e) => setValue(e.target.value)}
      onBlur={finish}
      onKeyDown={(e) => {
        if (e.key === 'Enter') {
          e.preventDefault();
          finish();
        }
        if (e.key === 'Escape') {
          e.preventDefault();
          e.stopPropagation();
          onCancel();
        }
      }}
    />
  );
};

export default InlineName;
```

```tsx
// A card that can be dragged and dropped on (dnd-kit). The whole card is the
// drag handle: a mouse drag starts after 5px, a touch drag after a 250ms press.
const DraggableCard = ({ id, children }: { id: string; children: ReactNode }) => {
  const { setNodeRef: setDragRef, listeners, isDragging } = useDraggable({ id });
  const { setNodeRef: setDropRef } = useDroppable({ id: `card:${id}` });
  const ref = useCallback(
    (el: HTMLLIElement | null) => {
      setDragRef(el);
      setDropRef(el);
    },
    [setDragRef, setDropRef],
  );
  // Pointer only: the card's own buttons (Open, Move) are the keyboard way in,
  // so dnd-kit's focusable "button" attributes aren't applied.
  return (
    <li ref={ref} className={isDragging ? styles.dragging : undefined} {...listeners}>
      {children}
    </li>
  );
};

// A column's empty space, so a card can be dropped at its end.
const ColumnDrop = ({ id, children }: { id: string; children: ReactNode }) => {
  const { setNodeRef, isOver } = useDroppable({ id: `column:${id}` });
  return (
    <div ref={setNodeRef} className={isOver ? `${styles.drop} ${styles.over}` : styles.drop}>
      {children}
    </div>
  );
};
```

```tsx
  const [announcement, setAnnouncement] = useState('');
  const [activeId, setActiveId] = useState<string | null>(null);
  // The order shown while dragging or saving, as on the main board: kept while
  // moves are saved, then until the stored order changes after the last save,
  // so the live query catching up never makes a card jump back.
  const [preview, setPreview] = useState<{ base: string | null; order: Record<string, string[]> } | null>(null);
  const [saving, setSaving] = useState(0);
  const refocusId = useRef<string | null>(null);
  const sensors = useSensors(
    useSensor(MouseSensor, { activationConstraint: { distance: 5 } }),
    useSensor(TouchSensor, { activationConstraint: { delay: 250, tolerance: 5 } }),
  );

  const stored: Record<string, string[]> = Object.fromEntries(
    columns.map((c) => [c.id, (cards.get(c.id) ?? []).map((n) => n.id)]),
  );
  const storedKey = JSON.stringify(stored);
  if (preview && preview.base === null && saving === 0) setPreview({ ...preview, base: storedKey });
  const shown =
    preview && (saving > 0 || preview.base === null || preview.base === storedKey) ? preview.order : stored;
  const notesById = new Map([...cards.values()].flat().map((n) => [n.id, n]));
  const columnName = new Map(columns.map((c) => [c.id, c.name]));
  const titleOf = (id: string) => notesById.get(id)?.title || 'Untitled';

  // After a move the card's Move button may be in another column: focus it again.
  useEffect(() => {
    const id = refocusId.current;
    if (!id) return;
    const button = document.querySelector<HTMLElement>(`[data-card-move="${CSS.escape(id)}"]`);
    if (button) {
      refocusId.current = null;
      button.focus();
    }
  });

  const save = async (noteId: string, columnId: string, ids: string[]) => {
    const { beforeId, afterId } = neighbors(ids, noteId);
    setAnnouncement(
      `Moved ${titleOf(noteId)} to ${columnName.get(columnId)}, position ${ids.indexOf(noteId) + 1} of ${ids.length}`,
    );
    setSaving((n) => n + 1);
    let result: PlaceResult | undefined;
    try {
      result = await placeNote(noteId, columnId, beforeId, afterId);
    } catch {
      toast({ message: 'Couldn’t move the card.' });
    } finally {
      setSaving((n) => n - 1);
      setPreview((p) => p && { ...p, base: null });
    }
    if (result?.dateChanged) {
      const before = result.before;
      toast({
        message: before.due?.doneAt === null ? 'Marked done' : 'Date reopened',
        actionLabel: 'Undo',
        onAction: () => void putBackPlace(before),
      });
    }
  };

  // Menu moves start from the order on screen: an earlier move may not be saved yet.
  const moveWithin = (noteId: string, columnId: string, move: CardMove) => {
    const ids = shown[columnId] ?? [];
    const index = moveIndex(ids, noteId, move);
    if (index === null) return;
    const next = moveToIndex(ids, noteId, index);
    setPreview({ base: null, order: { ...shown, [columnId]: next } });
    refocusId.current = noteId;
    void save(noteId, columnId, next);
  };

  const moveToColumn = (noteId: string, columnId: string) => {
    const from = Object.keys(shown).find((key) => shown[key].includes(noteId));
    const next = { ...shown, [columnId]: [...(shown[columnId] ?? []).filter((id) => id !== noteId), noteId] };
    if (from) next[from] = shown[from].filter((id) => id !== noteId);
    setPreview({ base: null, order: next });
    refocusId.current = noteId;
    void save(noteId, columnId, next[columnId]);
  };

  const targetOf = (id: string | number | undefined) => {
    const key = String(id ?? '');
    if (key.startsWith('card:')) return { type: 'card' as const, id: key.slice(5) };
    if (key.startsWith('column:')) return { type: 'column' as const, id: key.slice(7) };
    return null;
  };

  const onDragStart = ({ active }: DragStartEvent) => {
    setActiveId(String(active.id));
    setPreview({ base: null, order: shown });
  };

  const onDragOver = ({ active, over }: DragOverEvent) => {
    const target = targetOf(over?.id);
    if (!target) return;
    setPreview((p) => ({ base: p?.base ?? null, order: moveInColumns(p?.order ?? shown, String(active.id), target) }));
  };

  const onDragEnd = ({ active }: DragEndEvent) => {
    setActiveId(null);
    const id = String(active.id);
    const order = shown;
    const columnId = Object.keys(order).find((key) => order[key].includes(id));
    const was = Object.keys(stored).find((key) => stored[key].includes(id));
    if (!columnId || (columnId === was && order[columnId].indexOf(id) === stored[columnId].indexOf(id))) {
      setPreview(null);
      return;
    }
    void save(id, columnId, order[columnId]);
  };
```

```tsx
import { DropdownMenu } from 'radix-ui';
import type { ReactElement } from 'react';
import { useBoardColumns } from '../../lib/boards';
import menuStyles from '../ui/Menu.module.css';

type Props = {
  columnId: string | null;
  trigger: ReactElement;
  onPick: (columnId: string) => void;
  onRemove: () => void;
};

// Boards, each with its columns (the current one checked), and Remove from board.
const BoardMenu = ({ columnId, trigger, onPick, onRemove }: Props) => {
  const boards = useBoardColumns() ?? [];
  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger asChild>{trigger}</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Content className={menuStyles.content} align='end' sideOffset={6}>
          {boards.length === 0 && (
            <DropdownMenu.Item className={menuStyles.item} disabled>
              No boards yet
            </DropdownMenu.Item>
          )}
          {boards.map(({ board, columns }) => (
            <DropdownMenu.Sub key={board.id}>
              <DropdownMenu.SubTrigger className={menuStyles.item} disabled={columns.length === 0}>
                {board.name}
              </DropdownMenu.SubTrigger>
              <DropdownMenu.Portal>
                <DropdownMenu.SubContent className={menuStyles.content} sideOffset={4}>
                  <DropdownMenu.RadioGroup value={columnId ?? ''} onValueChange={onPick}>
                    {columns.map((column) => (
                      <DropdownMenu.RadioItem key={column.id} value={column.id} className={menuStyles.item}>
                        {column.name}
                      </DropdownMenu.RadioItem>
                    ))}
                  </DropdownMenu.RadioGroup>
                </DropdownMenu.SubContent>
              </DropdownMenu.Portal>
            </DropdownMenu.Sub>
          ))}
          {columnId && (
            <DropdownMenu.Item className={menuStyles.item} onSelect={onRemove}>
              Remove from board
            </DropdownMenu.Item>
          )}
        </DropdownMenu.Content>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  );
};

export default BoardMenu;
```
