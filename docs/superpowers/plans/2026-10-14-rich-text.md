# Rich Text Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Text notes get formatting (headings, emphasis, lists, quotes, code, links) with a Tiptap rich editor, stored as Markdown in `Note.content`, shown formatted on cards.

**Architecture:** One shared Markdown reader (`lib/markdown.ts`, a configured `marked` instance) defines how notes are read everywhere: cards render its tokens to React elements, search and list conversion use its plain text, and the editor's Tiptap Markdown extension is given its own instance of the same reader. The editor is a separate chunk loaded only on the note page; until it loads (or if it can't), the page shows the note read-only or falls back to the plain textarea.

**Tech Stack:** Next.js 16 Pages Router, React 19 (React Compiler lint), TypeScript, Tiptap 3.32 (`@tiptap/react`, `@tiptap/pm`, `@tiptap/starter-kit`, `@tiptap/markdown`, `@tiptap/extensions`), `marked` 17, Radix (`Toolbar`, `Popover`) + CSS Modules, lucide-react, Vitest + jsdom + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-14-rich-text-design.md`

## Global Constraints

- No server, data in the browser (IndexedDB via Dexie), Next.js 16 Pages Router, React 19 with the React Compiler lint rules, Radix + CSS Modules, WCAG 2.2 AA, functional text at least 11px.
- The database schema and the backup format (version 1) do not change.
- The board page must not load the editor.
- Scope: the body of text notes only. Titles and checklist items stay plain text.
- A single line break is a line break; indented text is not code; raw HTML is plain text, never HTML.
- Only `http:`, `https:` and `mailto:` links; a URL without a scheme gets `https://`; error copy "Enter a web or email address."
- Loading a note into the editor does not count as an edit.
- Fallback copy: "Formatting tools couldn't load. You can still edit the text."
- Code style: single quotes, JSX single quotes, 2-space indent, comments only where the code isn't obvious. There is no Prettier config; do not run Prettier (it rewrites quotes).
- Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. An old plain-text note containing Markdown-looking characters (`2 * 3`, `snake_case`, `<b>`) is edited once: its card and search text stay the same (only the stored form gains escapes). Test: Task 4, "keeps the text of old plain notes the same after an edit".
2. Opening a note and leaving without typing never saves it. Test: Task 4, "does not report a change when a note is opened".
3. `javascript:` and other unsafe links are never clickable on cards, never opened from the editor and never accepted in the link box. Tests: Task 1 `safeUrl`, Task 2 "shows links without making them clickable", Task 4 "never opens unsafe links", Task 5 "rejects an unsafe address".
4. The note's content changes while the editor is open (e.g. kind switch, Undo): the editor shows the new content without echoing a save. Test: Task 4, "loads a change made outside the editor without reporting it".
5. Converting list → note → list keeps item text exactly as typed, even with Markdown characters. Test: Task 3, "keeps item text as typed through a round trip".

## Findings from probing Tiptap 3.32 (scratch install, not in the repo)

- `Markdown.configure({ marked })` accepts an injected instance; Tiptap calls `instance.use()` on it, so each editor gets its own instance from `createMarked()`.
- With `breaks: true`, `'a\nb'` loads as a hard break and saves as `'a  \nb'`.
- Overriding marked tokenizers `code`, `html` and `tag` to return `undefined` turns off indented code and raw HTML; such text stays text. The editor then saves `<` as `&lt;`, so card and search code decode HTML entities.
- The editor adds a trailing empty paragraph, so saved Markdown can end in `\n\n`; it is trimmed (`tidyMarkdown`).
- `insertContent(text, { contentType: 'markdown' })` inserts parsed Markdown (used for pasting Markdown text).
- In jsdom, `useEditor` renders and toolbar commands work (`click` box, `Ctrl+A`, click a button). Typing with `user.type` into the contenteditable is unreliable, so tests drive the editor through commands and buttons; typing shortcuts are checked manually. ProseMirror needs `document.elementFromPoint` and `Range#getClientRects` stubs.

- [ ] **Step 3: Create `lib/markdown.ts`**

```ts
import { Marked, type Token } from 'marked';

// How Noteboard reads Markdown, shared by the editor, cards, search and
// conversion: GitHub-flavoured, a single line break is a line break, and
// indented text or raw HTML stay plain text. Returning undefined (not false)
// from a tokenizer switches that rule off.
export const createMarked = () =>
  new Marked(
    { gfm: true, breaks: true },
    {
      tokenizer: {
        code: () => undefined,
        html: () => undefined,
        tag: () => undefined,
      },
    },
  );

const reader = createMarked();

export const parseMarkdown = (markdown: string): Token[] => reader.lexer(markdown);

const NAMED: Record<string, string> = { amp: '&', lt: '<', gt: '>', quot: '"', apos: "'", nbsp: ' ' };

// Text tokens keep HTML entities (the editor saves "<" as "&lt;").
export const decodeEntities = (text: string) =>
  text.replace(/&(#x[0-9a-f]+|#\d+|[a-z]+);/gi, (match, code: string) => {
    if (code[0] !== '#') return NAMED[code.toLowerCase()] ?? match;
    const value = code[1].toLowerCase() === 'x' ? parseInt(code.slice(2), 16) : parseInt(code.slice(1), 10);
    return value > 0 && value <= 0x10ffff ? String.fromCodePoint(value) : match;
  });

// The words inline tokens show, without Markdown symbols.
const inlineText = (tokens: Token[] | undefined): string =>
  (tokens ?? [])
    .map((token): string => {
      switch (token.type) {
        case 'br':
          return '\n';
        case 'codespan':
        case 'escape':
          return token.text;
        default:
          if ('tokens' in token && token.tokens) return inlineText(token.tokens);
          return decodeEntities(typeof token.text === 'string' ? token.text : token.raw);
      }
    })
    .join('');

// One entry per line of text, in reading order.
const blockLines = (tokens: Token[]): string[] =>
  tokens.flatMap((token): string[] => {
    switch (token.type) {
      case 'space':
      case 'hr':
      case 'def':
        return [];
      case 'code':
        return token.text.split('\n');
      case 'list':
        return token.items.flatMap((item: { tokens: Token[] }) => blockLines(item.tokens));
      case 'blockquote':
        return blockLines(token.tokens ?? []);
      default:
        if ('tokens' in token && token.tokens) return inlineText(token.tokens).split('\n');
        return decodeEntities(token.raw).split('\n');
    }
  });

const linkUrls = (tokens: Token[]): string[] =>
  tokens.flatMap((token): string[] => [
    ...(token.type === 'link' ? [token.href as string] : []),
    ...('tokens' in token && token.tokens ? linkUrls(token.tokens) : []),
    ...(token.type === 'list' ? token.items.flatMap((item: { tokens: Token[] }) => linkUrls(item.tokens)) : []),
  ]);

export const markdownLines = (markdown: string): string[] =>
  blockLines(parseMarkdown(markdown))
    .map((line) => line.trim())
    .filter((line) => line !== '');

// Text plus link addresses, so search finds "booking.com" in a link.
export const toPlainText = (markdown: string): string => {
  const tokens = parseMarkdown(markdown);
  return [...blockLines(tokens), ...linkUrls(tokens)].join('\n');
};

export const isMarkdownEmpty = (markdown: string) => markdownLines(markdown).length === 0;

// Item text is plain, so characters Markdown would read as formatting are
// escaped and the note shows exactly what was typed.
const escapeText = (text: string) =>
  text
    .trim()
    .replace(/[\\`*_~[\]<>]/g, '\\$&')
    .replace(/^#/, '\\#')
    .replace(/^([-+])(?=\s)/, '\\$1')
    .replace(/^(\d+)([.)])/, '$1\\$2');

export const itemsToMarkdown = (items: { text: string }[]) =>
  items
    .filter((item) => item.text.trim() !== '')
    .map((item) => `- ${escapeText(item.text)}`)
    .join('\n');

// Only web and email links. An address without a scheme gets https://;
// "host:8080" is a port, not a scheme.
export const safeUrl = (input: string): string | null => {
  const value = input.trim();
  if (!value || /\s/.test(value)) return null;
  const hasScheme = /^[a-z][a-z0-9+.-]*:(?!\d)/i.test(value);
  const candidate = hasScheme ? value : `https://${value}`;
  try {
    const url = new URL(candidate);
    if (url.protocol === 'mailto:') return url.pathname.includes('@') ? candidate : null;
    if ((url.protocol === 'http:' || url.protocol === 'https:') && url.hostname.includes('.')) return candidate;
    return null;
  } catch {
    return null;
  }
};

export const looksLikeMarkdown = (text: string) =>
  /(^|\n) {0,3}(#{1,6} |[-*+] |\d+[.)] |> |```|---[ \t]*(\n|$))|\*\*\S[^*]*\*\*|~~\S[^~]*~~|\[[^\]]+\]\([^)\s]+\)|`[^`\n]+`/.test(
    text,
  );

export const tidyMarkdown = (markdown: string) => markdown.replace(/\s+$/, '');
```

```tsx
import type { Token } from 'marked';
import { Fragment, type ReactNode } from 'react';
import { decodeEntities, parseMarkdown } from '../../lib/markdown';
import styles from './MarkdownPreview.module.css';

const textOf = (token: Token) => decodeEntities(typeof token.text === 'string' ? token.text : token.raw);

const inline = (tokens: Token[] | undefined): ReactNode =>
  (tokens ?? []).map((token, index) => <Fragment key={index}>{inlineToken(token)}</Fragment>);

const inlineToken = (token: Token): ReactNode => {
  switch (token.type) {
    case 'strong':
      return <strong>{inline(token.tokens)}</strong>;
    case 'em':
      return <em>{inline(token.tokens)}</em>;
    case 'del':
      return <s>{inline(token.tokens)}</s>;
    case 'codespan':
      return <code>{token.text}</code>;
    case 'br':
      return <br />;
    // A click anywhere on a card opens the note, so links are shown, not followed.
    case 'link':
      return <span className={styles.link}>{inline(token.tokens)}</span>;
    case 'escape':
      return token.text;
    default:
      return 'tokens' in token && token.tokens ? inline(token.tokens) : textOf(token);
  }
};

const blocks = (tokens: Token[]): ReactNode =>
  tokens.map((token, index) => <Fragment key={index}>{block(token)}</Fragment>);

const block = (token: Token): ReactNode => {
  switch (token.type) {
    case 'space':
    case 'def':
      return null;
    // Not real headings: the card title is the heading.
    case 'heading':
      return (
        <p className={styles.heading} data-level={token.depth}>
          {inline(token.tokens)}
        </p>
      );
    case 'paragraph':
      return <p>{inline(token.tokens)}</p>;
    case 'text':
      return 'tokens' in token && token.tokens ? inline(token.tokens) : textOf(token);
    case 'list': {
      const items = token.items.map((item: { tokens: Token[] }, index: number) => <li key={index}>{blocks(item.tokens)}</li>);
      return token.ordered ? <ol start={typeof token.start === 'number' ? token.start : undefined}>{items}</ol> : <ul>{items}</ul>;
    }
    case 'blockquote':
      return <blockquote>{blocks(token.tokens ?? [])}</blockquote>;
    case 'code':
      return (
        <pre>
          <code>{token.text}</code>
        </pre>
      );
    case 'hr':
      return <hr />;
    default:
      return <p>{decodeEntities(token.raw)}</p>;
  }
};

const read = (markdown: string): Token[] | null => {
  try {
    return parseMarkdown(markdown);
  } catch {
    return null;
  }
};

type Props = { markdown: string; id?: string; className?: string };

// Renders Markdown from tokens to elements; nothing goes through innerHTML.
const MarkdownPreview = ({ markdown, id, className }: Props) => {
  const tokens = read(markdown);
  return (
    <div id={id} className={className ? `${styles.preview} ${className}` : styles.preview}>
      {tokens ? blocks(tokens) : <p>{markdown}</p>}
    </div>
  );
};

export default MarkdownPreview;
```

import { Extension } from '@tiptap/core';
import { Placeholder } from '@tiptap/extensions';
import { Markdown } from '@tiptap/markdown';
import { Plugin } from '@tiptap/pm/state';
import StarterKit from '@tiptap/starter-kit';
import type { marked } from 'marked';
import { createMarked, looksLikeMarkdown, safeUrl } from '../../lib/markdown';

// Plain-text pastes that look like Markdown arrive formatted. Pastes from
// web pages (text/html) are left to the editor, which keeps the formatting
// it supports.
const MarkdownPaste = Extension.create({
  name: 'markdownPaste',
  addProseMirrorPlugins() {
    const { editor } = this;
    return [
      new Plugin({
        props: {
          handlePaste: (_view, event) => {
            const data = event.clipboardData;
            if (!data || data.types.includes('text/html')) return false;
            const text = data.getData('text/plain');
            if (!looksLikeMarkdown(text)) return false;
            return editor.commands.insertContent(text, { contentType: 'markdown' });
          },
        },
      }),
    ];
  },
});

// A fresh set per editor: the Markdown extension registers itself on the
// marked instance it is given.
export const editorExtensions = () => [
  StarterKit.configure({
    heading: { levels: [1, 2, 3] },
    // Markdown can't store underline.
    underline: false,
    link: {
      openOnClick: false,
      autolink: true,
      linkOnPaste: true,
      defaultProtocol: 'https',
      isAllowedUri: (url) => safeUrl(url) !== null,
    },
  }),
  // Typed as the default marked export; a Marked instance has the same API.
  Markdown.configure({ marked: createMarked() as unknown as typeof marked }),
  Placeholder.configure({ placeholder: 'Note' }),
  MarkdownPaste,
];

```tsx
import { EditorContent, useEditor } from '@tiptap/react';
import { useEffect, useEffectEvent, useRef, useState } from 'react';
import { safeUrl, tidyMarkdown } from '../../lib/markdown';
import { editorExtensions } from './extensions';
import styles from './RichEditor.module.css';

export type RichEditorProps = {
  value: string;
  onChange: (value: string) => void;
  readOnly: boolean;
  autoFocus: boolean;
  // Where the formatting bar is drawn (under the editor's top bar).
  barSlot?: HTMLElement | null;
};

// Plain clicks place the cursor; Cmd/Ctrl+click follows a safe link.
export const openLinkOnModClick = (event: MouseEvent): boolean => {
  if (!(event.metaKey || event.ctrlKey)) return false;
  const link = event.target instanceof Element ? event.target.closest('a') : null;
  const url = safeUrl(link?.getAttribute('href') ?? '');
  if (!url) return false;
  window.open(url, '_blank', 'noopener,noreferrer');
  return true;
};

const RichEditor = ({ value, onChange, readOnly, autoFocus }: RichEditorProps) => {
  const [extensions] = useState(editorExtensions);
  // The Markdown the editor last reported, so a change from outside (not an
  // echo of the user's own edit) can be loaded in.
  const reported = useRef(value);
  const editor = useEditor({
    extensions,
    content: value,
    contentType: 'markdown',
    editable: !readOnly,
    autofocus: autoFocus ? 'end' : false,
    immediatelyRender: true,
    shouldRerenderOnTransaction: false,
    editorProps: {
      attributes: { class: styles.prose, role: 'textbox', 'aria-multiline': 'true', 'aria-label': 'Note' },
      handleClick: (_view, _pos, event) => openLinkOnModClick(event),
    },
  });

  const report = useEffectEvent((markdown: string) => onChange(markdown));

  // Only edits are reported; loading a note is not an edit.
  useEffect(() => {
    const onUpdate = () => {
      const markdown = tidyMarkdown(editor.getMarkdown());
      reported.current = markdown;
      report(markdown);
    };
    editor.on('update', onUpdate);
    return () => {
      editor.off('update', onUpdate);
    };
  }, [editor]);

  useEffect(() => {
    if (value === reported.current) return;
    reported.current = value;
    editor.commands.setContent(value, { contentType: 'markdown', emitUpdate: false });
  }, [editor, value]);

  useEffect(() => {
    editor.setEditable(!readOnly, false);
  }, [editor, readOnly]);

  return <EditorContent editor={editor} className={styles.content} />;
};

export default RichEditor;
```

    const chain = editor.chain().focus();
    if (editor.state.selection.empty && !editor.isActive('link')) {
      chain.insertContent({ type: 'text', text: url, marks: [{ type: 'link', attrs: { href: url } }] }).run();
    } else {
      chain.extendMarkRange('link').setLink({ href: url }).run();
    }
    onDone();
  };

  const remove = () => {
    editor.chain().focus().extendMarkRange('link').unsetLink().run();
    onDone();
  };

  return (
    <form className={styles.form} onSubmit={save}>
      <label htmlFor={inputId} className={styles.label}>
        Link address
      </label>
      <input
        id={inputId}
        className={styles.input}
        type='text'
        inputMode='url'
        autoComplete='off'
        autoFocus
        value={address}
        aria-invalid={invalid}
        aria-describedby={invalid ? errorId : undefined}
        onChange={(e) => {
          setAddress(e.target.value);
          setInvalid(false);
        }}
      />
      {invalid && (
        <p id={errorId} role='alert' className={styles.error}>
          Enter a web or email address.
        </p>
      )}
      <div className={styles.actions}>
        {active && (
          <button type='button' className={styles.button} onClick={remove}>
            Remove link
          </button>
        )}
        <button type='submit' className={`${styles.button} ${styles.primary}`}>
          Save
        </button>
      </div>
    </form>
  );
};

type Props = { editor: Editor; open: boolean; onOpenChange: (open: boolean) => void; active: boolean };

const LinkPopover = ({ editor, open, onOpenChange, active }: Props) => (
  <Popover.Root open={open} onOpenChange={onOpenChange}>

          <Link size={18} aria-hidden />

    </Toolbar.Button>
    <Popover.Portal>
      <Popover.Content
        className={styles.content}
        align='end'
        sideOffset={6}
        aria-label='Link'
        // Back to the text, not the button.
        onCloseAutoFocus={(event) => {
          event.preventDefault();
          editor.commands.focus();
        }}
      >
        <LinkForm editor={editor} active={active} onDone={() => onOpenChange(false)} />
      </Popover.Content>
    </Popover.Portal>
  </Popover.Root>
);

export default LinkPopover;

```ts
import { useEffect, useState, type ComponentType } from 'react';
import type { RichEditorProps } from './RichEditor';

type Load = () => Promise<{ default: ComponentType<RichEditorProps> }>;

export type RichEditorState =
  | { status: 'loading' }
  | { status: 'ready'; Editor: ComponentType<RichEditorProps> }
  | { status: 'failed' };

const loadRichEditor: Load = () => import('./RichEditor');

// The rich editor is a separate chunk, loaded only on the note page. If it
// can't load (offline before it was cached), the plain textarea is used.
export const useRichEditor = (load: Load = loadRichEditor): RichEditorState => {
  const [state, setState] = useState<RichEditorState>({ status: 'loading' });
  useEffect(() => {
    let live = true;
    load().then(
      (module) => {
        if (live) setState({ status: 'ready', Editor: module.default });
      },
      () => {
        if (live) setState({ status: 'failed' });
      },
    );
    return () => {
      live = false;
    };
  }, [load]);
  return state;
};
```
