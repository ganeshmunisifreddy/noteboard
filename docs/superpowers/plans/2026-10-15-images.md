# Images in Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notes and lists get an image gallery above the title: images are added from a file, the camera, paste or drop, shrunk on the device, stored in IndexedDB, shown on cards and in a full-screen viewer, and included in backups.

**Architecture:** `lib/images.ts` decodes and re-encodes images with the browser's `createImageBitmap` and canvas (swappable tools for tests). `lib/attachments.ts` stores image records (with thumbnails) in a new `attachments` table and full images in an `imageFiles` table (schema v3), and the note life cycle in `lib/notes.ts` keeps them in step. The board loads thumbnails once (`useBoardImages`) and cards render them; the editor shows a gallery and a Radix Dialog viewer; backups move to format version 2.

**Tech Stack:** Next.js 16 Pages Router, React 19 (React Compiler lint), TypeScript, Dexie 4 + dexie-react-hooks, Radix (`Dialog`), lucide-react, CSS Modules, Vitest + jsdom + Testing Library + fake-indexeddb.

**Spec:** `docs/superpowers/specs/2026-10-15-images-design.md`

## Global Constraints

- No server, data in the browser (IndexedDB via Dexie), Next.js 16 Pages Router, React 19 with the React Compiler lint rules, Radix + CSS Modules, WCAG 2.2 AA, functional text at least 11px.
- Images are stored apart from the note text, never inside `Note.content`.
- No new image-processing dependency; `createImageBitmap` and canvas only.
- Full image longest side 2048px; thumbnail 480px; never scale up. JPEG quality 0.85 for opaque images; transparency as WebP (0.9) where the browser can write it, otherwise PNG. Images within 2048px and under 1.5 MB are kept as they are (thumbnail still made).
- Limits: 20 images per note; source files over 25 MB refused.
- Copy: "Notes can have up to 20 images." · "That image is too large (over 25 MB)." · "Couldn't add <file name>: this browser can't read it." · "Couldn't add the image: storage is full." · "Image removed" (Undo) · "Drop to add images" · "Image unavailable" · `_N images (not included in the Markdown export)_` ("1 image").
- Adding, removing or describing an image bumps the note's `updatedAt`.
- Backup format version 2 adds `attachments`; version 1 still restores; version 3+ is "newer".
- Code style: single quotes, JSX single quotes, 2-space indent, comments only where the code isn't obvious; never run Prettier (no repo config; it rewrites quotes).
- Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Plan-level adjustments to the spec (decided while planning)

1. **Image data is stored as `ArrayBuffer` bytes plus a MIME type, not as `Blob`s.** Probing showed `fake-indexeddb` under jsdom returns stored `Blob`s broken, while `ArrayBuffer`s round-trip; bytes behave the same in real browsers and avoid old Safari Blob-in-IndexedDB issues. Display code builds a `Blob` from the bytes when needed. (Values read back may come from another realm, so code checks `byteLength`, never `instanceof ArrayBuffer`.)
2. **Full images live in their own table (`imageFiles: 'id'`).** `attachments` holds the details and the thumbnail bytes, so the board loads only thumbnails; the full image is read when it's shown (single-image gallery, viewer, backup).
3. **The viewer closes after Remove** (the toast offers Undo); simpler than moving to a neighbour.

## Review Focus

1. A brand-new, unsaved note whose first content is an image: the note is created, its URL updated, and leaving it doesn't move it to Trash as "empty". Test: Task 6, "saves a new note when its first image is added and keeps it on leaving".
2. Restoring a backup whose copy of a note is older than the local one: the local images stay; the backup's images for that note are ignored. Test: Task 3, "keeps local images when the local note is newer".
3. Deleting forever, emptying Trash and the 30-day purge leave no image data behind, and don't touch other notes' images. Test: Task 2, "deletes a note's images with the note, and only those".
4. Storage full part-way through a batch: earlier images stay saved, the failed one leaves nothing half-saved, and the message appears once. Test: Task 2, "leaves nothing half-saved when storage is full".
5. Pasting text together with an image: the text pastes where the cursor is (the paste isn't cancelled) and the image goes to the gallery. Test: Task 6, "adds a pasted image without cancelling a text paste".

```ts
export const FULL_SIZE = 2048;
export const THUMB_SIZE = 480;
export const MAX_FILE_BYTES = 25 * 1024 * 1024;
const KEEP_AS_IS_BYTES = 1.5 * 1024 * 1024;

export class ImageError extends Error {
  kind: 'unreadable' | 'too-large';
  constructor(kind: 'unreadable' | 'too-large') {
    super(kind);
    this.kind = kind;
  }
}

export const fitWithin = (width: number, height: number, max: number) => {
  const scale = Math.min(1, max / Math.max(width, height));
  return { width: Math.max(1, Math.round(width * scale)), height: Math.max(1, Math.round(height * scale)) };
};

// JPEG for photos and anything opaque; transparency needs WebP or PNG.
export const outputFormat = (hasAlpha: boolean, webp: boolean) =>
  !hasAlpha ? 'image/jpeg' : webp ? 'image/webp' : 'image/png';

const QUALITY: Record<string, number | undefined> = { 'image/jpeg': 0.85, 'image/webp': 0.9 };

export type Decoded = { width: number; height: number; hasAlpha: boolean; source: CanvasImageSource; close: () => void };

export type ImageTools = {
  decode: (file: Blob) => Promise<Decoded>;
  encode: (image: Decoded, width: number, height: number, type: string, quality?: number) => Promise<Blob>;
  canWriteWebp: () => Promise<boolean>;
};

export type ProcessedImage = {
  bytes: ArrayBuffer;
  type: string;
  width: number;
  height: number;
  thumb: ArrayBuffer;
  thumbType: string;
};

const MAY_HAVE_ALPHA = /^image\/(png|webp|gif|avif)$/;

const toBlob = (canvas: HTMLCanvasElement, type: string, quality?: number) =>
  new Promise<Blob>((resolve, reject) =>
    canvas.toBlob((blob) => (blob ? resolve(blob) : reject(new Error('Could not encode'))), type, quality),
  );

// Looks at a small copy for any pixel that isn't fully opaque.
const hasTransparency = (bitmap: ImageBitmap) => {
  const size = fitWithin(bitmap.width, bitmap.height, 64);
  const canvas = document.createElement('canvas');
  canvas.width = size.width;
  canvas.height = size.height;
  const context = canvas.getContext('2d', { willReadFrequently: true });
  if (!context) return true;
  context.drawImage(bitmap, 0, 0, size.width, size.height);
  const { data } = context.getImageData(0, 0, size.width, size.height);
  for (let i = 3; i < data.length; i += 4) if (data[i] < 255) return true;
  return false;
};

let webpSupport: Promise<boolean> | null = null;

// The browser applies the photo's EXIF orientation when decoding.
export const browserTools: ImageTools = {
  decode: async (file) => {
    const bitmap = await createImageBitmap(file);
    return {
      width: bitmap.width,
      height: bitmap.height,
      hasAlpha: MAY_HAVE_ALPHA.test(file.type) && hasTransparency(bitmap),
      source: bitmap,
      close: () => bitmap.close(),
    };
  },
  encode: (image, width, height, type, quality) => {
    const canvas = document.createElement('canvas');
    canvas.width = width;
    canvas.height = height;
    const context = canvas.getContext('2d');
    if (!context) return Promise.reject(new Error('No canvas'));
    context.imageSmoothingQuality = 'high';
    context.drawImage(image.source, 0, 0, width, height);
    return toBlob(canvas, type, quality);
  },
  // Some browsers silently write PNG when asked for WebP.
  canWriteWebp: () => {
    webpSupport ??= (() => {
      const canvas = document.createElement('canvas');
      canvas.width = 1;
      canvas.height = 1;
      return toBlob(canvas, 'image/webp').then(
        (blob) => blob.type === 'image/webp',
        () => false,
      );
    })();
    return webpSupport;
  },
};

export const processImage = async (file: File, tools: ImageTools = browserTools): Promise<ProcessedImage> => {
  if (!file.type.startsWith('image/')) throw new ImageError('unreadable');
  if (file.size > MAX_FILE_BYTES) throw new ImageError('too-large');
  let image: Decoded;
  try {
    image = await tools.decode(file);
  } catch {
    throw new ImageError('unreadable');
  }
  try {
    const type = outputFormat(image.hasAlpha, image.hasAlpha && (await tools.canWriteWebp()));
    const thumbSize = fitWithin(image.width, image.height, THUMB_SIZE);
    const thumb = await tools.encode(image, thumbSize.width, thumbSize.height, type, QUALITY[type]);
    const thumbPart = { thumb: await thumb.arrayBuffer(), thumbType: thumb.type || type };
    if (Math.max(image.width, image.height) <= FULL_SIZE && file.size <= KEEP_AS_IS_BYTES) {
      return { bytes: await file.arrayBuffer(), type: file.type, width: image.width, height: image.height, ...thumbPart };
    }
    const size = fitWithin(image.width, image.height, FULL_SIZE);
    const full = await tools.encode(image, size.width, size.height, type, QUALITY[type]);
    return { bytes: await full.arrayBuffer(), type: full.type || type, width: size.width, height: size.height, ...thumbPart };
  } catch {
    throw new ImageError('unreadable');
  } finally {
    image.close();
  }
};
```

```ts
export type AddFailure = { name: string; reason: 'unreadable' | 'too-large' | 'limit' | 'storage' | 'save' };

const byPosition = (a: Attachment, b: Attachment) => a.position - b.position;

// Images are part of the note: changing them is an edit.
const touch = (noteId: string) => db.notes.update(noteId, { updatedAt: Date.now() });

export const getAttachments = async (noteId: string) =>
  (await db.attachments.where('noteId').equals(noteId).toArray()).sort(byPosition);

// One image at a time, so a bad file doesn't stop the rest. Each image and
// the note's edit time are saved together or not at all.
export const addImages = async (
  noteId: string,
  files: File[],
  process: (file: File) => Promise<ProcessedImage> = processImage,
): Promise<AddFailure[]> => {
  const failures: AddFailure[] = [];
  for (const file of files) {
    if ((await db.attachments.where('noteId').equals(noteId).count()) >= MAX_IMAGES) {
      failures.push({ name: file.name, reason: 'limit' });
      continue;
    }
    let image: ProcessedImage;
    try {
      image = await process(file);
    } catch (error) {
      const tooLarge = error instanceof ImageError && error.kind === 'too-large';
      failures.push({ name: file.name, reason: tooLarge ? 'too-large' : 'unreadable' });
      continue;
    }
    try {
      await db.transaction('rw', db.notes, db.attachments, db.imageFiles, async () => {
        const last = (await getAttachments(noteId)).at(-1);
        const id = uuid();
        await db.attachments.add({
          id,
          noteId,
          position: (last?.position ?? -1) + 1,
          type: image.type,
          width: image.width,
          height: image.height,
          size: image.bytes.byteLength,
          alt: '',
          createdAt: Date.now(),
          thumb: image.thumb,
          thumbType: image.thumbType,
        });
        await db.imageFiles.add({ id, bytes: image.bytes });
        await touch(noteId);
      });
    } catch (error) {
      failures.push({ name: file.name, reason: isQuotaError(error) ? 'storage' : 'save' });
    }
  }
  return failures;
};

export const failureMessages = (failures: AddFailure[]): string[] => {
  const messages = failures.map((failure) => {
    switch (failure.reason) {
      case 'limit':
        return `Notes can have up to ${MAX_IMAGES} images.`;
      case 'too-large':
        return 'That image is too large (over 25 MB).';
      case 'storage':
        return 'Couldn’t add the image: storage is full.';
      case 'save':
        return `Couldn’t save ${failure.name}.`;
      default:
        return `Couldn’t add ${failure.name}: this browser can’t read it.`;
    }
  });
  return [...new Set(messages)];
};

export const describeAttachment = (id: string, alt: string) =>
```

```ts
// Image bytes travel in the JSON backup as base64.
export const toBase64 = (bytes: ArrayBuffer) => {
  const view = new Uint8Array(bytes);
  let binary = '';
  for (let i = 0; i < view.length; i += 0x8000) {
    binary += String.fromCharCode(...view.subarray(i, i + 0x8000));
  }
  return btoa(binary);
};

export const fromBase64 = (text: string): ArrayBuffer | null => {
  if (text.length % 4 !== 0 || !/^[A-Za-z0-9+/]*={0,2}$/.test(text)) return null;
  try {
    const binary = atob(text);
    const view = new Uint8Array(binary.length);
    for (let i = 0; i < binary.length; i += 1) view[i] = binary.charCodeAt(i);
    return view.buffer;
  } catch {
    return null;
  }
};
```

```ts
import { useCallback, useSyncExternalStore } from 'react';

type Entry = { url: string; users: number; timer?: ReturnType<typeof setTimeout> };

const entries = new WeakMap<ArrayBuffer, Entry>();
const RELEASE_DELAY_MS = 1000;

const acquire = (bytes: ArrayBuffer, type: string) => {
  let entry = entries.get(bytes);
  if (!entry) {
    entry = { url: URL.createObjectURL(new Blob([bytes], { type })), users: 0 };
    entries.set(bytes, entry);
  }
  clearTimeout(entry.timer);
  entry.users += 1;
};

// Freed a moment after the last user leaves, so a quick remount (React's
// Strict Mode, a card moving between columns) reuses the URL.
const release = (bytes: ArrayBuffer) => {
  const entry = entries.get(bytes);
  if (!entry) return;
  entry.users -= 1;
  if (entry.users > 0) return;
  entry.timer = setTimeout(() => {
    if (entry.users > 0) return;
    URL.revokeObjectURL(entry.url);
    entries.delete(bytes);
  }, RELEASE_DELAY_MS);
};

// A URL an <img> can show for stored image bytes; null until ready.
export const useObjectUrl = (bytes: ArrayBuffer | null | undefined, type: string): string | null => {
  const subscribe = useCallback(
    (notify: () => void) => {
      if (!bytes) return () => {};
      acquire(bytes, type);
      notify();
      return () => release(bytes);
    },
    [bytes, type],
  );
  return useSyncExternalStore(
    subscribe,
    () => (bytes ? (entries.get(bytes)?.url ?? null) : null),
    () => null,
  );
};
```

```tsx
import { useImageFile } from '../../lib/attachments';
import type { Attachment } from '../../lib/types';
import { useObjectUrl } from '../../lib/useObjectUrl';
import styles from './Gallery.module.css';

type ItemProps = { image: Attachment; index: number; total: number; single: boolean; onOpen: (index: number) => void };

const GalleryItem = ({ image, index, total, single, onOpen }: ItemProps) => {
  // A single image is shown large, so it uses the full image once loaded.
  const file = useImageFile(single ? image.id : null);
  const full = useObjectUrl(file?.bytes, image.type);
  const thumb = useObjectUrl(image.thumb, image.thumbType);
  const url = full ?? thumb;
  return (
    <button
      type='button'
      className={styles.item}
      aria-label={`Open image ${index + 1} of ${total}${image.alt ? `: ${image.alt}` : ''}`}
      onClick={() => onOpen(index)}
    >
      {url && <img src={url} alt='' className={styles.image} draggable={false} />}
    </button>
  );
};

type Props = { images: Attachment[]; pending: number; onOpen: (index: number) => void };

// The note's images, above the title.
const Gallery = ({ images, pending, onOpen }: Props) => {
  const count = images.length + pending;
  if (count === 0) return null;
  return (
    <div className={styles.gallery} data-count={Math.min(count, 3)}>
      {images.map((image, index) => (
        <GalleryItem
          key={image.id}
          image={image}
          index={index}
          total={images.length}
          single={count === 1}
          onOpen={onOpen}
        />
      ))}
      {Array.from({ length: pending }, (_, index) => (
```

```tsx
import { ChevronLeft, ChevronRight, Trash2, X } from 'lucide-react';
import { Dialog } from 'radix-ui';
import type { KeyboardEvent } from 'react';
import { useImageFile } from '../../lib/attachments';
import type { Attachment } from '../../lib/types';
import { useObjectUrl } from '../../lib/useObjectUrl';
import IconButton from '../ui/IconButton';
import styles from './ImageViewer.module.css';

const FullImage = ({ image, label }: { image: Attachment; label: string }) => {
  const file = useImageFile(image.id);
  const url = useObjectUrl(file?.bytes, image.type);
  if (file === null) return <p className={styles.missing}>Image unavailable</p>;
  return url ? <img src={url} alt={image.alt || label} className={styles.image} /> : <div className={styles.loading} />;
};

type Props = {
  images: Attachment[];
  index: number | null; // open when set
  readOnly: boolean;
  onIndexChange: (index: number | null) => void;
  onRemove: (image: Attachment) => void;
  onDescribe: (image: Attachment, alt: string) => void;
};

// Full-screen view of one image; Esc closes it and focus goes back to the
// gallery button that opened it.
const ImageViewer = ({ images, index, readOnly, onIndexChange, onRemove, onDescribe }: Props) => {
  const image = index === null ? undefined : images[index];
  const label = index === null ? '' : `Image ${index + 1} of ${images.length}`;
  const go = (next: number) => {
    if (next >= 0 && next < images.length) onIndexChange(next);
  };
  const onKeyDown = (event: KeyboardEvent) => {
    if (index === null || event.target instanceof HTMLInputElement) return;
    if (event.key === 'ArrowLeft') go(index - 1);
    if (event.key === 'ArrowRight') go(index + 1);
  };

  return (
    <Dialog.Root open={image !== undefined} onOpenChange={(open) => !open && onIndexChange(null)}>
      <Dialog.Portal>
        <Dialog.Overlay className={styles.overlay} />
        <Dialog.Content className={styles.content} aria-describedby={undefined} onKeyDown={onKeyDown}>
          {image && index !== null && (
            <>
              <div className={styles.bar}>
                <Dialog.Title className={styles.title}>{label}</Dialog.Title>
                {!readOnly && (
                  <IconButton label='Remove image' onClick={() => onRemove(image)}>
                    <Trash2 size={18} aria-hidden />
                  </IconButton>
                )}
                <Dialog.Close asChild>
                  <IconButton label='Close'>
                    <X size={18} aria-hidden />
                  </IconButton>
                </Dialog.Close>
              </div>
              <div className={styles.stage}>
                <IconButton label='Previous image' disabled={index === 0} onClick={() => go(index - 1)}>
                  <ChevronLeft size={22} aria-hidden />
                </IconButton>
                <FullImage key={image.id} image={image} label={label} />
                <IconButton label='Next image' disabled={index === images.length - 1} onClick={() => go(index + 1)}>
                  <ChevronRight size={22} aria-hidden />
                </IconButton>
              </div>
              {readOnly ? (
                image.alt && <p className={styles.alt}>{image.alt}</p>
              ) : (
                <label className={styles.describe}>
                  Description
                  <input
                    key={image.id}
                    className={styles.input}
                    defaultValue={image.alt}
                    placeholder='Describe this image'
                    onBlur={(e) => onDescribe(image, e.target.value)}
                  />
                </label>
              )}
            </>
          )}
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
};

export default ImageViewer;
```

```tsx
import { ImagePlus } from 'lucide-react';
import { useRef } from 'react';
import IconButton from '../ui/IconButton';

// Phones offer the camera from the same picker.
const AddImageButton = ({ onAdd }: { onAdd: (files: File[]) => void }) => {
  const input = useRef<HTMLInputElement>(null);
  return (
    <>
      <IconButton label='Add image' onClick={() => input.current?.click()}>
        <ImagePlus size={18} aria-hidden />
      </IconButton>
      <input
        ref={input}
        type='file'
        accept='image/*'
        multiple
        hidden
        onChange={(e) => {
          const files = [...(e.target.files ?? [])];
          e.target.value = '';
          if (files.length > 0) onAdd(files);
        }}
      />
    </>
  );
};

export default AddImageButton;
```
